# Examples

Transcripts are generated by `python -m examples.generate` against the configured model.

The command needs `GOOGLE_API_KEY`. Each turn goes through the same turn runner as the chat,
so a transcript shows what a customer would see. A provider error stops the run.
Generated files land in `examples/transcripts/`, with the model, the reference date, and the
commit id in their header, ready to commit. Handoff and usage files from the run go to a temporary
folder. No transcript is committed yet: the folder holds only `.gitkeep` until the first live run.

The five scripts are:

1. Violões up to R$ 1000, then an electroacoustic follow-up, then 10 installments.
2. The GD20 that was on Black Friday.
3. A regret request, a wrong email, then the right contact, the dates, and a handoff.
4. An address change, Saturday hours, strings, an off-topic question, and a manager discount.
5. The day-48 warranty tension on order 7, ending in a registered complaint.
